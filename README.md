# Portfólio - Lucas Bozyk Capoani

Portfólio pessoal desenvolvido em React e Vite para apresentar perfil profissional, stack técnica, projetos e canais de contato.

## Tecnologias

- React
- Vite
- JavaScript
- HTML5
- CSS3

## Estrutura

```text
src/
  components/
    cards/      # Cards reutilizáveis
    icons/      # Ícones SVG
    layout/     # Navegação, rodapé e elementos de fundo
    sections/   # Seções principais da página
    ui/         # Componentes genéricos de interface
  data/         # Conteúdo centralizado do portfólio
  styles/       # Estilos globais
```

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```
